## 対象と責任境界

この計画の対象はparticle identity/optionsからspawn admission、pending/live lifecycle、provider個別motionとsprite、source trigger、描画representation、asset reloadまで。狙いは全てを一つの共通演算に寄せることではなく、server記述particleとclient local effectが同じ所有基盤に安全に合流しつつ、意味を決める境界を保つこと。

- **唯一のlive-state ownerは `ParticleStore`**。active/pending instances、emitter/追跡状態、provider初期化後のparticle state、admission結果、tick、remove、render extractionをここで一貫して所有する。別のengine/storeやsource別particle lifetimeは作らない。
- packet/localの共通入口はtyped `SpawnRequest` とする。要求には `identity + validated typed options + position/velocity + source/context + limiter flags` を一まとまりで持たせる。`source/context` は比較・診断・必要なsource-specific動作に十分な識別性を持ち、packet decoded値とlocally sampled eventを取り違えない。受け入れ前に必要なtyped validationを終え、無効要求をgeneric particleに置換しない。
- **Protocol owner** はpacket framing/decode/transport、wire IDとsource-protocol translation、option bytesの完全消費、未知/壊れたpayloadの安全な拒否を担当する。粒子optionの意味/provider選択・生成・lifetime/render表現はparticles側。protocol層へprovider実装を移さない。
- **Environment/block/entity/item/event owner** はauthoritative semantic triggerとclient-local samplingを所有し、必要なworld/entity状態からSpawnRequestを作る。serverがpacketで既に表現したeventをclientが再samplingして重ねない契約をsourceごとに決める。local visual-only sourceはlocalで一度だけ生成する。server-world/gameplay authorityやserver simulationは変更しない。
- **Physics/world owner** はcollision queryやblock/fluid/light/tintのworld情報を提供する。particles側はquery結果を用い、各provider固有のmotion/update/衝突適用規則を保持する。particle motionをworld physicsのauthorityにしない。
- **Resource owner** はreload世代と順序付きatlas descriptor/spriteの寿命・差替えを所有する。particlesはidentityごとのsprite consumer/provider mapping、missing provider/sprite時の失敗表現を決める。old generationのsprite参照がreload後のinstance/extractionへ漏れない契約を置く。
- **Renderer** はParticleStoreのrender-ready representationをconsumeする。provider/source policyをrendererへ移さない。Java render typeを単にopaque/translucent二値に畳んで一致と扱わず、blend/depth/light/color-alpha/sprite/facing/special modelを比較対象にする。
- option, resource, target-entity解決失敗は別々のfailure class。unknown kind/option mismatchはno-spawn; registered provider with missing spriteはJava/Rustの実資源規則に従った別挙動として観察・記録する。

## 対象と責任境界

対象は全sound system: event/weighted variant/redirect解決、seeded choice、logical instanceの開始・遅延・更新・loop・stop・破棄、category/mix/gain、listener・entity attachment・spatialization、native rendering、music/ambient scheduling、subtitle通知適格性とHUD上の方向・期限表示、resource reload、menu/world/connection遷移である。packet音だけに縮めず、UI/local feedback、block/entity sound、musicとclient ambientも含める。`SoundSource.VOICE` のcategoryが存在することはvoice chatの機能・session・transportの存在証明ではない。

- **Audio semantic owner:** event lookup、weighted/redirect chainと乱数、resolved sound semantics、logical instance ID/lifetime、遅延/tickable/loop、stop条件、source category gain、listener/spatial policy、再生可否と字幕イベント通知を所有する。サーバのtrigger・target・seed・除外やmenu/world状態の生成元にはならない。
- **Audio native worker:** device/context/source/buffer等native handleを単独所有し、semantic commandを実行して完了・失敗を返す。ゲーム規則、音楽状況選択、字幕表示を決めない。native error/no-device/asset errorは音を失敗させてもconnectionやgame tickを止めない。
- **Resources:** pack priority/stack、asset pathとimmutable catalog/asset-generation snapshotの準備・公開を所有する。Audioはsnapshotを消費し、weighted selectionやactive playback/native bufferをresource managerへ押し戻さない。reloadは新snapshotの切替と旧generationのactive/native資源破棄を一つの明確な境界として扱う。
- **Protocol/server:** transport はtyped sound commandを運ぶ。serverはtrigger、recipients/targets、seed、excluded player等の権限を持つ。Pomme clientのsemantic handoffは `pomme-client/src/app/core.rs:5244-5314` (AppCore network sound dispatch)、decodeは `pomme-client/src/net/handler.rs:578-606` (handle_game_packet sound-event conversion); `pomme-client/src/net/handler.rs:2654-2737` (handle_raw_ui_sound, handle_raw_ui_entity_sound, handle_raw_ui_stop_sound)。Steel server送信経路は `Client/third_party/SteelMC/steel-core/src/world/level_effects.rs:451-508,526-568` (LevelEffects::play_sound / play_sound_at; external Client checkout pinned at `0b1f87c36a664f08d81397e942fb1e19f6eb282b`; assigned worktree submodule is uninitialized)。audioは受信seedをvariant選択に使い、再度server権限を推測しない。server excluded cueをclient predictionが重複再生しない契約を保つ。
- **Context producers:** physics/living/nonliving/world/menu ownersがlistener pose、entity attachment、world/screen contextと遷移を提供する。audioが位置追従・spatial renderingを行うが、entity/world/menuの発生policyを所有側から奪わない。disconnect/world/menu transitionのteardown対象を区別する。
- **Menus/HUD:** menusはcategory/accessibility settingとscreen/music contextを提供する。HUDはaudioからimmutable subtitle display rows/notificationsを受け、group/repeat, direction, expiry, layout/renderを所有する。字幕対象判定はaudio semanticsに置き、HUDでsound eventやassetを再解決しない。

## 互換にする設計

1. **immutable catalog snapshot + explicit resolution result:** resource ownerがpack priorityを解決した immutable asset generationをpublishし、audio semantic ownerはそのsnapshotに対してevent lookup→weighted entry→redirect chain→file metadataを一回解決する。instanceにはevent/source/category/seed/selected asset generationと適用済み volume/pitch/stream/attenuation/preload/subtitleを保持する。redirectはwrapper順に volume/pitchを乗算し、streamをOR、target metadata/attenuation/preload規則を公式と照合して適用する。循環redirectは当該eventを失敗させ、missing entry/fileは診断して無音化し、tick/connectionを失敗させない。乱数選択はserver seedありではそのseedの規則的な同じ候補順/weightで再現し、seedなしは通常random。`preload`は捨てず、公式と同じreload寿命で適用する。
2. **logical instance != native voice:** semantic ownerはlogical instance IDとevent/entity identity、source filter、lifecycle、latest position/gain/pitchを保持する。workerはlogical IDからnative source/bufferへ対応づけ、native IDを外へ漏らさない。event/entity stopとStopAllは公式filterに対応し、completed/failure通知を一度だけ返す。自然終了後generic 20-tick retention、delayed scheduling、manual loop/restart、tickable updatesは別のlogical instance semanticsとして実装し、native hardware loopingだけで代用しない。Pommeの`LOGICAL_SOUND_RETENTION_TICKS=20`はmenu曲終了後のdelay補正 (`audio/mod.rs:28-31,646-668,1237-1239,1345-1349`) であり、汎用voice retentionの証拠ではない。worker active mapがnative voiceを所有して終了時回収する (`audio/mod.rs:779-833,1128-1175`)。openal source limit/rejectionを明示的なfailureとして扱う。
3. **deterministic tick order:** tickごとに `(1) transport commands + context/listener/entity snapshots受領 → (2) due scheduled instances/tickable logical updates → (3) listener/spatial/category+master gain計算 → (4) worker voice start/update/stop commands → (5) accepted subtitle observable rowsの公開` とする。Native completion/failureは次のsemantic updateで確定し、HUDはimmutable rowsを消費する。relative/NONEのcue rangeとsilence/device-failure前通知は公式の通知境界を反映し、subtitle eligibilityを音が聞こえたかだけに依存させない。
4. **distinct teardown by cause:** pack reloadは新snapshotをpublishしold generationのvoice/decoded buffersをFIFOで破棄。connection endはserver-originated logical instances、world switchはentity-following/local-world ambience、menu switchはsituational musicを止め/更新、HUD transitionはsubtitle historyをHUDでclear/expireする。それぞれ別のowner signalを使う。native shutdownはworker自身がcontextをclose。同期FIFO decodeの現状でgeneration fencingは不要。非同期化時にgeneration tokenが必須。
5. **music/ambient are policy, not device:** music scheduler/context policyはmenu/world/screen/living contextから公式Musicsのpolicyを選び、frequency/delay/replace/fade/pauseと終了をAudio semantic instancesへ指示する。ambient producersはbiome/underwater/bubble等のcontext ownerがtickし、loop/crossfade/mood/distance/tickable propertiesをaudioへ渡す。server packetsとlocal predictionにはorigin/authority identityを持たせ二重再生を抑止する。`VOICE` categoryは音量slotに留め、音声チャットsessionが別途確認されない限りsession stateを捏造しない。
6. **native degradation:** no device/library, source allocation refusal, corrupt/unsupported OGG, missing asset, cyclic redirect, reload overlapはevent-local失敗・rate-limited診断として処理し、workerの他音声、game tick、transport lifecycleをblockingさせない。device enumeration/reconnect/Doppler/virtualizationの互換性はbackend根拠と実機検証が揃うまで一致と宣言しない。
